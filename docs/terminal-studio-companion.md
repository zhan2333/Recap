# Terminal Studio 伴随模式

实现依据：[已确认的交互设计稿](https://recap-design-archive.rio2333.chatgpt.site/designs/preview/companion)。

在讲次标题栏或讲义 PDF 导航栏点击 Terminal Studio，也可使用 ⌘⇧T。首次打开默认显示在右侧；分隔条可调整宽度。展开、恢复伴随与收起都保留同一个 SwiftTerm、shell、输入草稿和引用。窄窗口改为上下排列，可滚动查看。

会话属于当前讲次工作区。查看讲义和返回播放页不会重建终端；离开该工作区或明确开始新会话时结束旧进程。讲次菜单仍可另开独立 Studio 窗口，该窗口有自己的会话。

## 引用与产物

- PDF：引用当前页或文字选区，捕获文件、页码、文字和选区位置。
- 播放：引用当前全局时间或选中重点。重点回源定位到原话前 3 秒并暂停。
- 翻页、播放和重新选择不会改变已添加的引用。引用可以移除；填入终端后可从引用历史回到来源。
- 带引用的输入使用经过控制字符清理的 bracketed paste；用户在终端按 Return 提交。终端未开启该能力时保留草稿，提示先启动 CLI。
- 产物区可直接在阅读区打开本讲讲义。讲义重新生成后保留页码、缩放和可见位置，播放器刷新保留播放状态。
- 播放页的右侧重点列表在 Studio 显示时收起，下方 Focus Rail 保留。

课程级汇总 PDF 没有明确的讲次归属，因此不接入讲次 Studio。
